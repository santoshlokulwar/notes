ES6 / ECMAScript features

Q1 let and const — why const cannot be reassigned? +

const prevents reassignment of the variable reference, not mutation of the referenced object. Object properties can still change unless the object is frozen.

const user = { name: 'A' };
user.name = 'B'; // allowed
// user = {} // not allowed (reassignment)

Object.freeze(user); // shallow freeze

Deep freeze recursively freezes nested objects for stronger immutability checks, but adds overhead and is mostly used in development.

Q2 Arrow functions and why they do not have prototype +

Arrow functions are concise and lexically bind this. They do not create their own this, arguments, or prototype.

Arrow functions cannot be constructors (new does not work), so JavaScript does not assign them a prototype property.

Q3 What is prototype in JavaScript? +

Prototype is the object used for inheritance in JavaScript. Objects can share methods through the prototype chain, which avoids duplicating behavior per instance.

Q4 Template literals +

Template literals use backticks and solve interpolation, multiline strings, and embedded expressions.

const name = 'Santosh';
const msg = `Hello ${name}
Welcome!`;
Q5 Map and Set +

Map stores key-value pairs where keys can be any type and preserves insertion order. Set stores unique values and also preserves insertion order.

Q6 Default parameters +

Default parameters provide fallback values when an argument is missing or undefined.

function greet(name = 'Guest') {
  return `Hello ${name}`;
}
Q7 Destructuring arrays and objects +

Destructuring extracts values from arrays/objects into variables in concise syntax.

const [a, b] = [10, 20];
const { id, name } = { id: 1, name: 'S' };
Q8 Spread vs Rest operator +

Spread expands iterable/object values. Rest collects remaining values into an array/object.

const nums = [1, 2];
const arr = [...nums, 3]; // spread

function sum(...values) { // rest
  return values.reduce((t, n) => t + n, 0);
}
Q9 Object literals (ES6 enhancements) +

ES6 object literals support property shorthand, method shorthand, and computed property names.

const x = 10;
const key = 'score';
const obj = {
  x,
  greet() { return 'hi'; },
  [key]: 100
};
Q10 Classes in JavaScript +

Classes are syntactic sugar over prototype-based inheritance, providing cleaner syntax for constructor, methods, static methods, and extends.

Q11 Modules (import/export): named and default +

Named export allows multiple values per file; default export allows one primary export per file. Both can coexist in one module.

// math.js
export const add = (a, b) => a + b;
export default function subtract(a, b) { return a - b; }

// usage
import subtract, { add } from './math.js';
Q12 Promises and promise states +

A Promise represents eventual completion/failure of an async operation.

  • Pending - initial state
  • Fulfilled - operation succeeded
  • Rejected - operation failed
Q13 New data structures: Map, Set, WeakMap, WeakSet +

WeakMap/WeakSet hold weak references (object keys only) and are not enumerable. Useful for memory-safe metadata/caching tied to object lifecycle.

Q14 for...of loop +

for...of iterates over values from iterable objects (arrays, strings, maps, sets) via iterator protocol.

Q15 Symbols +

A Symbol is a unique immutable primitive, commonly used as object property keys to avoid naming collisions and support meta-programming patterns.

Q16 Generators +

Generators are functions that pause/resume using yield and return iterator objects for step-wise execution.

function* ids() {
  yield 1;
  yield 2;
}
const it = ids();
it.next(); // { value: 1, done: false }
Q17 Useful built-in methods (Array, Object, String) +
  • Array: find, findIndex, includes, flat, flatMap, at, toSorted
  • Object: entries, values, fromEntries, assign, hasOwn
  • String: includes, startsWith, endsWith, replaceAll, padStart
