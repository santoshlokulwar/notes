Realm DB essentials

Q1 Why pick Realm in React Native apps? +

Realm offers fast local object storage, live-updating query results, and offline-first patterns. It avoids heavy serialization work you often do with plain JSON storage.

Q2 How do Realm writes work, and why transactions matter? +

All create/update/delete operations must be inside a write transaction. Transactions ensure atomic updates and protect data integrity if app crashes mid-operation.

Q3 What is Realm schema migration strategy? +

Bump schema version and provide migration logic to transform existing records. Never remove/rename fields in production without backward-compatible migration steps.

Q4 How do live objects/results affect UI logic? +

Realm objects are live references, not immutable snapshots. UI can update automatically, but business logic should avoid mutating shared live objects outside controlled flows.

Q5 Common performance tips for Realm? +

Query only required fields/data sets, use indexed fields for frequent lookups, batch writes in one transaction, and avoid loading very large result sets in one render path.
