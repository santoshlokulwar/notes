Core concepts

Q1 What is state uplifting (lifting state up)? +

State uplifting means moving state from a child to the nearest common parent so several children share one source of truth. That keeps data flow one-way and keeps siblings in sync.

Q2 What is JSX? +

JSX is a syntax extension that looks like HTML in JavaScript. It compiles to React.createElement (or equivalent) calls so you can describe UI in a declarative way.

Q3 What is the Context API and when do you use it? +

Context lets you pass data through the tree without prop-drilling every level. Use it for rarely changing global-ish data (theme, auth user, locale). Avoid putting everything in context or you can trigger wide re-renders.

Q4 Functional components vs class components — why prefer functional today? +

Functional components with hooks are the default in modern React: simpler mental model, easier composition, no this binding issues, and alignment with concurrent features. Class lifecycle methods map to hooks (useEffect, useLayoutEffect, etc.).

Hooks & performance

Q5 What is the difference between useMemo and useCallback? +

useMemo memoizes a computed value so you skip expensive recalculation when deps are unchanged. useCallback memoizes a function reference so child components that depend on referential equality (React.memo) do not re-render unnecessarily.

Q6 What is debouncing in UI handlers? +

Debouncing delays executing a function until the user stops firing events for a set time (e.g. search input). It cuts work versus running on every keystroke.

Redux & data

Q7 What is Redux Thunk? +

Redux Thunk is middleware that lets you dispatch functions, not only plain action objects. Inside the thunk you can run async code and call dispatch / getState.

Q8 Describe the Redux architecture at a high level. +
  • Single store — one global state tree
  • Actions — plain objects describing what happened
  • Reducers — pure functions: (state, action) → new state
  • Dispatch — sends actions to the store
  • Optional middleware (thunk, saga) for side effects
Q9 Is data in the Redux store encrypted by default? +

No. Redux stores plain JS objects in memory. Encryption or secure persistence is your responsibility (e.g. secure storage, obfuscation) if you need it.

Q10 What is React Query (TanStack Query)? +

TanStack Query (formerly React Query) manages server state: fetching, caching, background refresh, deduping requests, and keeping UI in sync with remote data — complementary to client state libraries.

Types & ecosystem

Q11 What is static type checking (e.g. TypeScript)? +

Types are checked at compile time (or by the type checker before bundle). Variable and function types are known or inferred so many bugs are caught before runtime.

Q12 What is GraphQL? +

GraphQL is a typed query language for APIs. Clients request exactly the fields they need from often a single endpoint, which reduces over-fetching and under-fetching compared to naive REST.

Q13 What is a peer dependency? +

A peer dependency declares that your package expects the host app to install a compatible version (e.g. react, react-dom) instead of nesting its own copy — avoiding duplicate React and version conflicts.

Q14 What’s new in React 19 (high level)? +

React 19 builds on React 18 with Actions for async forms, the use() hook for reading promises/context, stronger Suspense patterns, resource preload APIs, and more mature Server Components support.

Q15 What are micro frontends? +

Micro frontends split the UI into independently deployable pieces (by team or domain), composed in the browser or via a shell app — similar ideas to microservices for the frontend.

New architecture

Q1 What is JSI in React Native’s New Architecture? +

JSI (JavaScript Interface) is a C++ layer that lets JS talk to native code without the old bridge. It avoids JSON serialization overhead, can run synchronously where appropriate, and underpins Turbo Modules and Fabric.

Q2 What are Turbo Modules? +

Turbo Modules replace legacy native modules: they use JSI for direct, faster (optionally synchronous) calls, lazy loading, and better performance than bridge-based modules.

Q3 What is Fabric rendering? +

Fabric is the new renderer: JSI-based C++ UI pipeline with synchronous layout options, better alignment with concurrent React, and less bridge overhead than the old UIManager + shadow thread model.

Rendering & lists

Q4 What is the Virtual DOM in React Native? +

React still builds a JS tree of your UI. Reconciliation diffs that tree; updates are applied to native views, not a browser DOM.

Q5 FlatList vs map() for long lists? +

FlatList virtualizes: it mounts only visible rows (+ small window). Mapping thousands of Views kills memory and JS thread. Use FlatList / SectionList for large data.

Q6 What is list virtualization? +

Only a slice of items is rendered and recycled as you scroll, keeping node count and work bounded.

Q7 Overlapping views without position — what helps? +

Use zIndex (and elevation on Android) so the intended view draws on top when siblings overlap in the same parent.

Hooks & navigation

Q8 useEffect vs useLayoutEffect +

useEffect runs after paint — good for subscriptions, logging, most data work. useLayoutEffect runs after DOM/native layout but before paint; use when you must measure or mutate layout to avoid flicker (blocking).

Q9 What is React Navigation? +

The common JS routing library for RN: manages navigation state and transitions via stack, tab, drawer, and other navigators.

Q10 What is Universal Linking / deep linking (concept)? +

HTTP/HTTPS links open your app (or store) on the right screen. iOS Universal Links and Android App Links require domain verification and OS configuration alongside React Navigation linking setup.

Production & performance

Q11 How do you remove console.log in React Native production? +

Use the Babel plugin transform-remove-console enabled only for production builds so Metro strips logs at compile time.

Q12 What usually causes RN performance problems? +
  • JS thread blocking (heavy sync work on main JS bundle)
  • Unnecessary re-renders
  • Large lists without virtualization
  • Heavy legacy bridge traffic (improves with New Architecture)
  • Memory leaks (listeners, timers, subscriptions)
Q13 How can you fetch live / real-time data? +

Polling, WebSockets, GraphQL subscriptions, or real-time DB SDKs. WebSockets are often the most efficient for true push streams.

Q14 How do push notifications work (high level)? +

App registers with FCM (Android) / APNs (iOS). Server sends to the provider; OS wakes or delivers to the app. You handle tokens, permissions, background modes, and notification channels (Android).

Q15 React Native 0.81 — what stands out? +

Broad Android 16 support with edge-to-edge defaults, experimental faster iOS precompiled builds, better errors/DX, legacy SafeAreaView deprecation, JSC moved to community package, stricter env/Metro expectations.

Q16 Pressable vs TouchableWithoutFeedback? +

Pressable is the modern primitive: flexible children, hit slop, ripple on Android, pressed state styles. Touchables are older; TouchableWithoutFeedback gives no visual feedback — use when you wrap non-text custom UI and handle feedback yourself.

Q17 What is Flipper used for? +

Flipper is a desktop debugger platform; plugins inspect layout, network, Redux, databases, crash logs, etc. (ecosystem has shifted over time; still useful in many RN setups.)

Functions in JS

Q1 Function declaration vs function expression — and hoisting? +

A declaration function f() {} is fully hoisted (body lifted). An expression var g = function() {} follows variable hoisting: g is hoisted as undefined until the assignment line runs.

Q2 What is an anonymous function? +

A function without a name in the source, usually as an expression: setTimeout(() => {}, 0) or arr.map(x => x * 2). A bare function() {} as a statement is invalid; assign or wrap it.

Q3 Named function expression — can you call the inner name from outside? +

var b = function a() {} — you call b() externally. The name a is usable inside the function (e.g. recursion). Use a base case to avoid infinite recursion.

Q4 Parameters vs arguments +

Parameters are the names in the function definition. Arguments are the values you pass at call time.

Q5 What are first-class functions? +

Functions are values: assign to variables, pass as arguments, return from other functions.

Callbacks, promises, async

Q6 What is a callback? What is callback hell? +

A callback is a function passed to another to run later (often async). Callback hell is nested callbacks for sequential async steps (order → pay → summary → wallet), hard to read and error-handle.

Q7 What is inversion of control with callbacks? +

You hand execution to another API; you don’t control when or if your callback runs (errors, timing). Promises/async patterns help regain structured flow.

Q8 Promise.all, allSettled, race, any +
  • all — waits for all; rejects fast on first failure
  • allSettled — waits for every promise to settle (success or fail)
  • race — first settled (fulfill or reject) wins
  • any — first fulfillment wins; if all reject, aggregated error
Q9 async / await rules of thumb +

An async function always returns a promise. await pauses inside an async function until a promise settles. fetch() returns a promise you can await.

this: call, apply, bind

Q10 Explain call, apply, and bind +

All set this for a function. call takes arguments as a list. apply takes arguments as an array. bind returns a new function with this (and optional partial args) fixed for later invocation.

Scope, hoisting, TDZ

Q11 What is hoisting? +

During compilation, declarations are conceptually moved to the top of their scope. Initializations are not hoisted — only the binding (var → undefined; let/const → TDZ until line).

Q12 What is the temporal dead zone (TDZ)? +

For let and const, from scope entry until the declaration line, the binding exists but must not be read — accessing it throws ReferenceError. This enforces no use-before-declaration.

Q13 Script scope vs global scope (modules) +

Classic scripts at top level create true globals (on window in browsers). ES modules have their own top-level scope — not the same as browser global; exports are explicit.

Q14 What is a closure? +

A function that retains access to variables from its outer lexical scope even after the outer function finished.

Q15 Event loop — microtasks vs macrotasks +

JS runs one call stack. When empty, it drains microtasks (promise thens, queueMicrotask) before taking the next macrotask (timer, I/O). Starvation happens if microtasks enqueue forever.

Q16 undefined vs null +

undefined — default unset value, missing property, no return. null — intentional “no object” often from APIs. Both are falsy; types differ (typeof null === 'object' is a historical bug).

Q17 forEach vs map +

map returns a new array of transformed values. forEach returns undefined and is for side effects; you can’t break it like a normal loop (no built-in break).

Q18 Remove duplicates from an array of objects +

Use a Set with serialized keys, or filter with a Map keyed by id, or reduce. For primitives, [...new Set(arr)] suffices.

Q19 Second largest number without sorting +

One pass: track max and second; for each value update both. Handle duplicates and edge cases (length < 2).

function secondLargest(nums) {
  let max = -Infinity, sec = -Infinity;
  for (const n of nums) {
    if (n > max) { sec = max; max = n; }
    else if (n > sec && n !== max) sec = n;
  }
  return sec === -Infinity ? null : sec;
}
Q20 What is a polyfill? +

Code that implements a newer API on older runtimes so your script can use the feature everywhere (e.g. Promise, Array.prototype.at).

Q21 Strongly vs loosely coupled modules +

Tight coupling — modules know too much about each other; hard to change one without breaking others. Loose coupling — clear interfaces, dependency inversion, easier testing and swaps.

React / JS puzzles

Q1 Class setState puzzle: what prints when? + 
// state.a starts at 10
this.setState({ a: 20 }, () => console.log("first", this.state.a));
console.log("second", this.state.a);

Typical React: setState is asynchronous. The sync line runs first — second often still shows 10 (batched update not flushed). The callback runs after commit — first shows 20. If you meant a free variable a = 10 unrelated to state, logs would still show 10 for that variable since setState doesn’t mutate locals.

Q2 Hoisting snippet — what is logged? + 
console.log("b: " + b);
function getName() { console.log("Try programiz.pro"); }
const a = 2;
var b = 3;
let c;
console.log(c);

var b is hoisted → first log prints b: undefined. getName is hoisted. const a / let c are in TDZ until their lines (no access above). Last console.log(c) prints undefined (declared, not assigned).

Sequences & arrays

Q4 First 10 numbers: first=2, second=8, third=2×second−first, then repeat pattern? +

Given rule t = 2*b - a for the third from first two: starting 2, 8 → third = 14. If the pattern is “every next = 2×prev − prevPrev” (linear recurrence), you get: 2, 8, 14, 20, 26, 32, 38, 44, 50, 56 for ten terms.

Q5 Reorder: [1,3,4,34,5] → [5,3,1,4,34] +

Swap indices 0↔4 and 1↔2: [arr[4], arr[2], arr[1], arr[3], arr[0]] or destructuring swaps in place.

[arr[0], arr[4]] = [arr[4], arr[0]];
[arr[1], arr[2]] = [arr[2], arr[1]];
Q6 Longest consecutive sequence in an array +

Put values in a Set. For each number that is the start of a sequence (n-1 not in set), walk n+1 while present. Track max length and slice. Example: [1,10,11,12,14,2,3,4,5] → longest consecutive values [1,2,3,4,5]. For [...,15,16] the run 10..16 wins if you treat consecutive integers (your second example implies 13 is implied missing in array but sequence is 10–16 — clarify with interviewer; algorithm finds longest chain of integers each +1 present).

Strings & structures

Q7 Balanced parentheses: () true, ({}) true, }{ false +

Use a stack: push on ([{, pop on closing with matching open. If stack empty on close or wrong top → false. End stack must be empty.

Q8 Last “run” of equal characters: aa bbbcccddd → ddd +

Iterate chars (ignore spaces or split tokens). Track current char + count; on change, update “last run”. After loop, return the last run string.

Q9 N students × M subjects — total marks excluding lowest subject average globally? +

For each subject compute average across all students; find subject with minimum average; for each student sum marks skipping that one column (or subtract that subject’s score once).

Q10 Longest subsequence in a string (interview variant) +

Clarify: longest substring without repeat, longest palindrome subsequence, or LCS between two strings? Each maps to a standard pattern (sliding window, DP LCS/LPS). State assumptions before coding.

Q11 Add element at first position of an array +

arr.unshift(x), arr.splice(0,0,x), [x, ...arr] (new array), [x].concat(arr).
