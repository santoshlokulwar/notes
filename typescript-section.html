TypeScript basics

Q1 What is TypeScript and how is it different from JavaScript? +
  • JavaScript is dynamically typed (type checks happen at runtime).
  • TypeScript is statically typed (type checks happen at compile time).
  • TypeScript is a superset of JavaScript and compiles to JavaScript.
  • Type inference means TS can figure out some types automatically.
Q2 Common TypeScript types to remember +

string, number, boolean, RegExp, object, array, tuple, enum, any, unknown, never, void, and union types like string | number.

Q3 any vs unknown vs never vs void +
  • any: skips type safety, accepts anything.
  • unknown: can hold anything, but must be narrowed before use.
  • never: value never occurs (e.g., function that always throws).
  • void: usually no return value from a function.
Q4 Arrays and tuples in TypeScript +

Array example: let marks: number[] = [10, 20]. Tuple example: let tuple: [string, number, boolean] = ['santosh', 3, true]. Tuple defines type by position.

let tuple: [string, number, boolean] = ['santosh', 3, true];
let a = ['santosh', 3, true];
// tuple = a; // not allowed, a is a normal array
Q5 Object types with type and interface + 
type StringOrNumber = string | number;
type StringOrNumberArray = (string | number)[];

type Gui = {
  name: string;
  active: boolean;
  albums: StringOrNumberArray;
};

interface GuiProfile {
  name?: string;
  active: boolean;
  albums: StringOrNumberArray;
}

Use ? for optional properties. Optional keys are checked at compile time.

Q7 Function types, optional params, and defaults + 
const add = (a: number, b: number): number => {
  return a + b;
};

type AddFunction = (a: number, b: number) => number;
let addFn: AddFunction = function (c, d) {
  return c + d;
};

const addWithOptional = (a: number, b: number, c?: number): number => {
  return c !== undefined ? a + b + c : a + b;
};

const addWithDefault = (a: number, b: number, c: number = 2): number => {
  return a + b + c;
};
Q8 Type assertions +

Use assertion when you know a narrower type than TS can infer.

function getValue(): string | number {
  return 'token';
}

const value = getValue() as string;
console.log(value.toUpperCase());

Auth flow and testing

Q9 Implement auth flow: get token, set token, refresh token + 
type Tokens = { accessToken: string; refreshToken: string };

class AuthService {
  private accessToken: string | null = null;
  private refreshToken: string | null = null;

  async login(username: string, password: string): Promise {
    const tokens = await this.getToken(username, password);
    this.setToken(tokens);
  }

  private async getToken(username: string, password: string): Promise {
    // call login API
    return { accessToken: 'access', refreshToken: 'refresh' };
  }

  private setToken(tokens: Tokens): void {
    this.accessToken = tokens.accessToken;
    this.refreshToken = tokens.refreshToken;
  }

  async refreshAccessToken(): Promise {
    if (!this.refreshToken) throw new Error('No refresh token');
    // call refresh API with refreshToken
    this.accessToken = 'new-access-token';
  }
}
