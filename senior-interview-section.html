Senior-level interview questions

Q1 How do you decide architecture for a new React Native app? +

Start from product constraints: offline needs, release cadence, team skill, observability, and performance targets. Choose patterns that optimize delivery speed first, then scale by measurable bottlenecks.

Q2 Describe a production incident you handled end-to-end +

Strong answer should cover detection, impact assessment, rollback/mitigation, root-cause analysis, and prevention actions. Interviewers look for calm prioritization and communication quality.

Q3 How do you mentor mid-level/junior engineers? +

Use clear ownership, pair-debugging on real tasks, code review teaching notes, and growth plans with measurable goals. Balance short-term delivery with long-term team capability.

Q4 How do you handle disagreement on technical direction? +

Align on decision criteria (cost, risk, user impact), run a time-boxed spike if needed, then commit to one path. Document decision records so future teams understand trade-offs.

Q5 How do you ensure long-term app performance and reliability? +

Define budgets (startup time, crash-free rate, frame drops), instrument key flows, monitor regressions in CI, and enforce release checklists. Reliability is process plus tooling, not one-time optimization.
